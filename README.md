# DCTtool Enterprise - Cloud Web Application
Developed by Deepak Pal

इस फोल्डर में DCTtool का पूरा वेब एप्लीकेशन (Web App) मौजूद है, जिसे Google Chrome या किसी भी ब्राउज़र से चलाया जा सकता है।

---

## 🌟 इसकी विशेषताएँ:
1. **कोई इंस्टॉलेशन नहीं:** ऑफिस के किसी भी सदस्य को अपने कंप्यूटर पर कोई सॉफ्टवेयर या सेटअप इंस्टॉल नहीं करना पड़ेगा।
2. **डायरेक्ट यूआरएल (URL):** सिर्फ लिंक खोलकर एक्सेल फाइल अपलोड करें, वैलिडेशन देखें और तैयार स्प्लिट टेम्पलेट्स (ZIP) डाउनलोड करें।
3. **सेंट्रल ऑटो-अपडेट:** जब भी आप नियमों में कोई बदलाव करेंगे, आप सिर्फ इस कोड को अपडेट करेंगे और सभी यूज़र्स को पेज रीलोड (Refresh) करते ही नया नियम मिल जाएगा।
4. **28 बिजनेस रूल्स:** थ्रिफ्ट बैलेंस को 0.00 करने का नियम, 30-03-2025 डेट कैपिंग नियम, सेविंग्स डिपॉजिट डेट सिंक नियम — सब कुछ 100% एक्टिव है।

## 🚀 लाइव क्लाउड यूआरएल कैसे बनाएँ (Free in 2 Minutes):

### स्टेप 1: GitHub पर अपलोड करें
1. [github.com](https://github.com) पर जाएँ और एक नया रिपॉजिटरी (Repository) बनाएँ (जैसे `dcttool-web`).
2. इस `DCT-Cloud-WebApp` फोल्डर के सभी फाइलों को उस रिपॉजिटरी में पुश/अपलोड कर दें।

### स्टेप 2: Render.com पर फ्री में लाइव करें
1. [render.com](https://render.com) पर जाएँ और अपने GitHub अकाउंट से फ्री साइन अप (Sign In) करें।
2. **New +** बटन दबाएँ और **Web Service** चुनें।
3. अपनी `dcttool-web` रिपॉजिटरी को सेलेक्ट करें।
4. सेटिंग्स:
   - **Name:** `dcttool`
   - **Environment:** `Python 3`
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `gunicorn server:app`
   - **Instance Type:** `Free`
5. **Create Web Service** पर क्लिक करें।

👉 **बस! 1-2 मिनट में आपको एक लाइव ऑनलाइन लिंक मिल जाएगा (जैसे: `https://dcttool.onrender.com`).**  
यह लिंक आप ऑफिस के सभी लोगों को दे सकते हैं। वे अपने फोन या कंप्यूटर के क्रोम में इसे सीधे खोलकर यूज़ कर सकेंगे!
